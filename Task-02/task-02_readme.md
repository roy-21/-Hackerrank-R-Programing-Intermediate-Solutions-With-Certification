# Top Two Emirates – Revenue Potential Analysis (R)

##  Problem Overview
You are a marketing analyst for a cosmetic company operating across seven Emirates in the UAE.  
Using sales data from **2017**, the objective is to identify the **top two Emirates with the highest revenue potential for 2018**.

The cosmetic industry is expected to grow at a rate of **10% annually**, which must be reflected in the final revenue estimation.

---

## Input Data
The input CSV file contains the following columns:

| Column Name     | Description |
|-----------------|-------------|
| Emirates        | Name of the Emirate |
| Customer_name   | Customer name |
| Purchase_date   | Date of purchase |
| Amount          | Purchase amount (may contain typos) |

---

##  Data Cleaning Rules

### 1. Purchase Date Format
- Expected format: `dd-mm-yyyy`
- If the month value is greater than `12`, the date is incorrectly entered in `mm-dd-yyyy` format  
  → Swap day and month to correct it.

### 2. Year Corrections
- Incorrect year values such as `2027`, `2037`, and `2047` are corrected to `2017`.

### 3. Amount Column Cleaning
- Remove all non-numeric characters from the `Amount` column.  
  **Examples:**
  - `10$5` → `105`
  - `1%58` → `158`
  - `1,79` → `179`

---

##  Revenue Calculation Logic

### Step 1: Average Revenue Per Month (ARPM)
For each **customer within an Emirate**:

1. Identify the customer's **first purchase date**
2. Calculate the number of days from that date to `31-12-2017`
3. Convert days into months: Total_months = Total_days / 30
4. Calculate the **total revenue** generated by the customer
5. Compute Average Revenue Per Month:

ARPM = Total_revenue / Total_months
---

### Step 2: Estimated Revenue for 2018

- **Customer Level**

Estimated_2018 = ARPM × 12


- **Emirate Level**
- Sum the estimated revenues of all customers within the Emirate

---

##  Growth Adjustment
- Select the **top two Emirates** based on estimated revenue
- Increase their estimated revenue by **10%**
- Round the final value to the **nearest integer**

---

##  Output
The final output contains:

| Column Name | Description |
|------------|-------------|
| Emirate    | Name of the Emirate |
| Estimated_revenue | Estimated 2018 revenue (rounded) |
